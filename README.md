## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/smailsedrati00-afk/portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
